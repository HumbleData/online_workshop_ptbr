## Fonte da tradução

O conteúdo do workshop em português brasileiro é mantido em [PyLadiesSalvador/humbledata-iniciantes-ptbr](https://github.com/PyLadiesSalvador/humbledata-iniciantes-ptbr). Esse repositório serve como _source of truth_ da tradução; este repositório (`online_workshop_ptbr`) apenas hospeda a versão implantada via JupyterLite.

Para sincronizar atualizações da tradução, execute `./sync.sh` na raiz do projeto.
